# docs

三种性质的东西，分开放，因为读它们的时机完全不同。

| | 什么时候读 |
|---|---|
| `rules/` | **动对应的包之前。** 每条都是踩过的坑，带着「为什么」和「违反了会怎样」。各包下的 `CLAUDE.md` 薄指针会在你进那个目录时提醒你读哪一份 |
| `guides/` | 要接那件事的时候。zenith-printer 的对接方式、表达式引擎选型的调研 |
| `archive/` | 考古。设计基线 v1–v6，决策 1–72 的原始记录。**结论已经吸收进 `rules/`**，这里留的是当时的推理过程与被否掉的方案 |

跨栈的硬规则（那些没有任何目录指针会提醒到你的）留在仓库根的 `CLAUDE.md` 里。
**新规则默认写进 `rules/`**，要进根文件得先证明没有哪个目录能提醒到它。
