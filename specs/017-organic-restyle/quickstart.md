# 实机走查：Organic 风格前端重构

起一个本地实例，按顺序走完。**第 2 步必须断网做** —— 内网部署取不到远程字体，
而字体加载失败是静默的，有网时永远看不出问题。

```
CGO_ENABLED=0 go build -o /tmp/nexus ./cmd/nexus
NEXUS_JWT_SECRET=... NEXUS_ADMIN_EMAIL=... NEXUS_ADMIN_PASSWORD=... \
NEXUS_ALLOWED_EMAIL_DOMAINS=example.com NEXUS_DB_PATH=/tmp/qs.db /tmp/nexus seed 60
```

---

**1. 十二个页面没有一页还是旧外观。**
逐页打开：概览、资产、类别、字段（含字段组页签）、型号（含厂商页签）、状态、
持有方、账号、角色、导入、审计、登录。每页截图。
底色是暖奶油、主动作是陶土橙、面板是大圆角、按钮与输入框是药丸。
**任何一页保留深色或旧圆角都是不通过。**（SC-001）

**2. 断网后字体不变。**
断开外网（或用浏览器 DevTools 拦截 `fonts.googleapis.com` 与 `fonts.gstatic.com`），
硬刷新。标题与统计数字仍是 Caprasimo、正文仍是 Figtree、中文仍是 Noto Sans SC。
**回退到系统字体即不通过。**（SC-002）

**3. 二进制体积在预算内。**
`ls -l` 构建产物，与 v0.11.0 的 31.7 MB 相比，**增量不超过 8 MB**。
超出则按 plan.md 的风险表处理 —— 修订规格，不是放宽这一条。（SC-009）

**4. 深色彻底不见了。**
账号偏好里没有主题选项，导航栏没有深浅切换。
在浏览器里把系统主题切成深色再刷新 —— 界面**仍是浅色**。
`grep -rn "dark:" web/src` 只应命中零处。（FR-001）

**5. 全选本页与扩选全部。**
资产页筛出 40 台以上、每页 20 条。点表头勾选框 → 本页 20 条全选，
表格下方出现横幅。点横幅里的「选中符合当前筛选的全部 N 条」→ 批量条显示总数。
翻到第 2 页 → 选中状态还在。（FR-012 / FR-013）

**6. Shift 连选。**
勾第 3 行，按住 Shift 点第 9 行 → 第 3–9 行全选。
再按住 Shift 点第 6 行 → 第 6–9 行取消。（FR-014）

**7. 筛选变化不丢选。**
选中若干台，改筛选条件让其中一部分不再命中 →
批量条的计数**不减少**，改回筛选后那些设备仍是选中态。（FR-015 / SC-005）

**8. 单台设备不必先勾选。**
鼠标移到某一行，行尾出现三个按钮。点「打印标签」→ 直接对这一台生效。
**全程没有勾选动作，也没有进入详情页。**（FR-016 / FR-017 / SC-004）

**9. 批量条的出现与让位。**
一台都不选 → 底部没有批量条。选一台 → 出现。
滚到列表底部 → **最后一行没有被批量条遮住**。（FR-018 / FR-019）

**10. 空态。**
筛到没有任何设备命中 → 显示空状态，并有一键清除筛选。（US2 场景 7）

**11. 概览页。**
统计卡的四个数字与在对应筛选下的资产列表条数一致。
类别分布条的填充比例与台数占比相符，数值右对齐且等宽。
「待我处理」的每一条点击后跳到已筛好的资产列表。（FR-020 / SC-001）

**12. 八个元数据页形态一致。**
字段、字段组、型号、厂商、状态、持有方、账号、角色 —— 标题行、筛选栏、表格、
翻页条的形态一致。任选一页做一次点击行编辑、一次右键操作、
一次会被拒绝的操作 → **拒绝显示在对话框内部**。（FR-021 / FR-023 / FR-026）

**13. 类别页与审计页。**
类别页不搜索时是树，搜索时切平铺并显示完整路径，清空恢复成树。
审计页的前后值新旧可分，且**把浏览器调成灰度后仍可分**（不只靠颜色）。（FR-022 / FR-005）

**14. 英文界面不溢出。**
切到英文，重走第 1 步的十二页。
**药丸控件里没有换行、统计卡数字没有溢出、表头没有挤成两行。**（SC-007 / FR-024）

**15. 键盘可达性不低于改造前。**
从页面顶部按 Tab 走到底：每个可交互元素都到得了，**焦点位置始终看得见**。
重点看陶土橙焦点环在奶油底上的对比。
对话框打开后焦点被困在里面，Esc 能关。（SC-008 / FR-009）

**16. 筛选与翻页仍在地址栏里。**
筛几个条件、翻到第 3 页，点进一台设备再返回 → 筛选与页码都还在。
按浏览器后退 → 回到刚才那台设备，**不是**把搜索框的每次击键倒一遍。（FR-025）

**17. 既有行为回归。**
`GET /api/categories` 仍是数组（zenith 的数据源按数组解析）；
导入导出、打印、流转、`nexus verify` 全部照旧。**服务端一行没改，这一步应当无事发生。**
