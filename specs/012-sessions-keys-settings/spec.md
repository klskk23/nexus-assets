# 012 · 会话续期、API 密钥、账号设置与接口文档

## 缘起

四件事在同一轮里，因为它们是同一个问题的四个面：**一个已登录的账号可以携带什么**。

- 8 小时的 JWT 到期就是登出，没有续期，也没有吊销手段（`token_version` 列自 001 起就在，从没被读过）。
- 脚本要调接口，只能拿人的密码去登录，或者把一张会过期的 JWT 抄进配置里。
- 语言和主题只存在某一台浏览器的 localStorage 里，换台电脑就要重选。
- 接口契约只在仓库里的 `openapi.yaml`，没有能点开就试的地方。

## 决策

### 决策 73：刷新令牌进 HttpOnly Cookie，每次续期都轮换

访问令牌缩短到 **15 分钟**，续期靠一个**页面脚本读不到**的 Cookie —— 这是关键：
localStorage 里那张短命令牌被偷走值不了多少钱，而真正值钱的那张不在 JS 能碰到的地方。

`sessions` 表存的是**令牌的哈希**，不是令牌：数据库被拖走也换不出活会话。
每次续期都**轮换**——在铸造新令牌的同一个事务里作废旧的，所以一张令牌只能用一次。
**重放一张已经轮换掉的令牌**，意味着这条链上有两个持有者，而没有办法分辨谁是小偷，
所以**整个 family 一起吊销**。这也是前端刷新必须**单飞**的原因：
页面挂载时并发六个查询，六次并行续期里有五次是重放。

Cookie 的 `Secure` 跟着请求走（`X-Forwarded-Proto` 也算），
否则开发机上的 http 会让 Cookie 永远送不到。

### 决策 74：API 密钥等同于创建它的账号

`Authorization: Bearer nxk_<前缀>.<密钥>`，中间件先看前缀就知道是哪一类凭证，
不必拿两种校验互相试。**只存哈希**，明文只在创建响应里出现一次。

权限就是那个人自己的权限：本版本没有角色，唯一的准入边界是邮箱白名单，
再造一套权限模型等于对「谁可以做这件事」给出第二个答案。

`last_used_at` **最多一分钟写一次**：这一列是为了看出「哪把钥匙已经没人用了」，
这个问题不需要精确到每次请求，而每请求一次写库会把所有 API 调用都挤进那唯一的写连接。

### 决策 75：语言与主题存在账号上

`users` 加 `lang`/`theme` 两列，`GET/PATCH /me`。**字段缺席=不动，空字符串=跟随系统**，
后者是一种选择，必须能表达。浏览器仍留一份，只为首屏不闪；两台机器有分歧时以账号为准。

### 决策 76：Swagger UI 内嵌进二进制

`/api/docs` 与 `/api/openapi.yaml` 都由程序自己提供，资产 `go:embed` 进二进制（约 +2MB）。
理由是这套系统跑在内网：一个需要外网才能打开的参考文档，
恰恰在有人真的伸手去够它的时候是坏的。文档页从同源的 localStorage 取当前登录态，
所以「Try it out」是带着身份直接打的，而不是一排必然 401 的按钮。

契约文件是 `specs/001-asset-ledger-demo/contracts/openapi.yaml` 的副本
（`internal/httpapi/docs/openapi.yaml`）—— go:embed 够不到包目录之外。
两者不一致时以 001 那份为准，改完记得同步。

## 界面

右上角账号菜单：**设置** / 一键换主题 / 退出登录。
主题留在菜单里是因为它每天点；其余都进设置对话框，那里的选择一年做两次。

设置对话框：界面（语言、主题）· API 密钥（列表、新建、右键撤销）· 接口文档入口。
新建的密钥**只显示一次**，带复制按钮（走 `lib/clipboard.ts`，见 011 的教训）。
