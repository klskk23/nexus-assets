# 实机走查：流体内容列

这一轮的核心验收是**一个比例**，而比例只有在真实布局里才存在 ——
jsdom 不做布局，`getBoundingClientRect()` 恒返回 0。所以走查不是补充，**它就是验收**。

```
CGO_ENABLED=0 go build -o /tmp/nexus ./cmd/nexus
NEXUS_JWT_SECRET=... NEXUS_ADMIN_EMAIL=... NEXUS_ADMIN_PASSWORD=... \
NEXUS_ALLOWED_EMAIL_DOMAINS=example.com NEXUS_DB_PATH=/tmp/qs.db /tmp/nexus seed 60
```

## 0. 先跑脚本

```sh
node specs/020-fluid-content-column/measure.mjs
```

它量五档窗口的留白与右缘距离，**不通过就退出码 1**。

> **脚本在决策 135 换过断言。** 它现在要求**留白为 0、右缘距屏幕恒 52px**；
> 020 当初要求的是「留白占比恒 24%、地板档内容列恰为 960」。下面第 1、2 步随之改了。

**三条规则在同一台机器上的实测**：

| 视口 | 包含块 | 018（固定 960） | 020（76% 流动） | **135（铺满）** |
|---|---|---|---|---|
| 3840 | 3484 | 留白 2524（72.4%） | 留白 836（24%） | **0** |
| 2560 | 2204 | 留白 1244（56.4%） | 留白 529（24%） | **0** |
| 1920 | 1564 | 留白 604（38.6%） | 留白 375（24%） | **0** |
| 1440 | 1084 | 留白 124（11.4%） | 留白 124（11.4%） | **0** |
| 1366 | 1010 | 留白 50（5.0%） | 留白 50（5.0%） | **0** |

018 的毛病是留白**随窗口无界生长**，020 治住了生长；135 治的是留白本身。
注意 1440 / 1366 两档 018 与 020 完全相同 —— 那是 960 地板在起作用，
也是 020 能承诺「窄屏无回归」的原因。**135 把地板一起去掉了，这两档因此变了。**

---

**1. 双向验证（这一步不能省）。**
把 `AppShell` 内容列的 `div` 加回任何宽度类（`w-[min(100%,max(960px,76%))]` 或
`max-w-[960px]` 都行），重跑脚本 —— **必须报错**。去掉，**必须通过**。
一条只见过它通过的版面断言，不构成任何证据。（原 SC-005）

**2. 窄屏会变，要看的是「只变宽度」。**
1440 / 1366 / 1280 三档打开十六个路由。内容列**应当**比 018 宽
（1440 下 960 → 1084），这是预期而不是回归。
要确认的是**除了宽度什么都没动**：字号、行高、圆角、间距、控件尺寸一律不变，
表格不出现横向滚动条，对话框仍按自己的 `sm:max-w-*` 收口。

**3. 一条规则，一处声明。**

```sh
grep -rn "max-w-\[960px\]\|max-w-\[760px\]\|max-w-\[640px\]" web/src --include='*.tsx'
```

**命中必须恰好一处**：`features/common/ListToolbar.tsx` 的 `max-w-[640px]`。

那一处**是搜索框，不是内容列**，必须留着。它和 `TransferForm` 删掉的那处是同一个数字 640 ——
一次批量替换就会把它一起改掉，而且**不会有任何测试报错**，表现是搜索框在宽屏上拉成一整行。
走查时顺手在 2560 下看一眼搜索框：它应当仍是 640 上限，不是一整行。（SC-003 / FR-007）

**4. 超宽屏上的三件事都是预期的，不是缺陷。**
在 2560 打开：表格的列被拉开、时间线的分隔线横贯内容列、导入页的步骤卡很宽卡内空。
这三条在规格的「已接受的代价」里，开发者看过截图后明确接受。**看到它们不要去修。**

**5. 字号行高圆角没有变。**
2560 下量一行 `<td>` 的高度 —— 仍是 48px；量表格框圆角 —— 仍是 28px；量正文 —— 仍是 14px。
**只有宽度流动**，任何一处随窗口变化的字号都是越界。（FR-009）

**6. 服务端一行没改。**

```sh
git diff main --stat -- internal/ cmd/ migrations/   # 必须为空
```

（SC-004）

**7. 文档里不再有与代码相反的数字。**
